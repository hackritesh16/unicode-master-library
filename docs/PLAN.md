# Development Plan

The authoritative phase-by-phase plan, feature requirements, agent workflow and completion criteria are maintained in [MASTER_PROMPT.md](MASTER_PROMPT.md).

The current implementation status must be audited against the code and CI and is tracked in [PROGRESS.md](PROGRESS.md).

Do not use this file as evidence that a feature is implemented. A feature is complete only when its user-facing behavior, tests and CI are verified; device-only work must be explicitly marked as device-tested or not device-tested.
